## Research and Publication

### MemoryArchitect - Policy-Driven Memory Governance for LLM Agent Systems

Research focus: external memory governance for LLM agents, including write policies, metadata/provenance, TTL and decay, contradiction handling, retrieval eligibility, and token-budget arbitration.

**Why it matters:** long-running agents need memory that is useful, auditable, bounded, and safe. The core idea is to manage memory as a governed resource rather than a passive chat log or naive similarity search layer.
